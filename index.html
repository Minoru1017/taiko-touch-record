使用說明

兩種記錄方式:
  1. 本頁表單:先在「GitHub Token 設定」儲存一次 Token → 填寫紀錄 →「產生預覽」→ 勾選確認 →「同步到 GitHub」。沒有 token 時,可「複製紀錄內容」再用 GitHub 網頁編輯貼上,或貼給 Cursor agent。
  2. Cursor 手機版 agent:對這個 repo 說「記錄今天的手感」,agent 會先列草稿,回覆「確認同步」後才寫入並 push。
